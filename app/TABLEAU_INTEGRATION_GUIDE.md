## 3. Power BI Integration & Visual Construction

### Step 3.1: Data Ingestion
1. Open **Power BI Desktop**.
2. On the **Home** tab, click **Get Data → Text/CSV**.
3. Browse to:
   `c:\Users\HASINI\OneDrive\Desktop\plotter\tableau_exports\`
4. Select `tableau_crypto_daily_panel.csv` and click **Load**.
5. Repeat for `tableau_crypto_summary_by_asset.csv`, `tableau_hypothesis_tests.csv`, and `tableau_ml_predictions.csv`.

*(Optional Live Web Connection)*: Instead of local files, select **Get Data → Web** and enter `http://127.0.0.1:5000/api/export/daily-panel`.

### Step 3.2: Data Modeling & Relationships
1. Click on the **Model view** icon on the left sidebar.
2. Drag the `name` column from `tableau_crypto_summary_by_asset` to the `name` column in `tableau_crypto_daily_panel`.
3. Set Cardinality: **1 to Many (1:*)**, Cross filter direction: **Single**.
4. Drag `name` from `tableau_crypto_summary_by_asset` to `tableau_ml_predictions` (`name` column).

### Step 3.3: Visual Recipes for Power BI

#### Visual 1: Market Concentration (Pareto Chart)
- **Visual Type:** Line and Clustered Column Chart.
- **Data Source:** `tableau_crypto_summary_by_asset`.
- **Shared Axis:** `name`.
- **Column Values:** `avg_mcap_usd` (Sort descending).
- **Line Values:** Create a Quick Measure for **Running Total of Average Market Cap %**.
- **Filter:** Top 10 by `avg_mcap_usd`.
- **Insight:** Bitcoin holds 59.5% and the top 3 hold 77.8% of tracked market capitalization.

#### Visual 2: Weekend Volume Contraction (Test 1)
- **Visual Type:** Clustered Column Chart or Box and Whisker.
- **Data Source:** `tableau_crypto_daily_panel`.
- **Axis:** `is_weekend` (False = Weekday, True = Weekend).
- **Values:** Average of `vol_24h`.
- **Insight:** Average daily volume drops by $69.1 billion (-36.5%) during weekends ($p = 5.9 \times 10^{-6}$, Cohen's $d = -1.05$).

#### Visual 3: Volatility Disparity: Stable-Value vs. Volatile (Test 2)
- **Visual Type:** Clustered Column Chart.
- **Data Source:** `tableau_crypto_summary_by_asset`.
- **Axis:** `asset_type`.
- **Values:** Average of `volatility_daily_sd_pct`.
- **Insight:** Volatile tokens average 5.65% daily return SD vs. 0.07% for Stablecoins (Rank-biserial $r = 1.00$).

#### Visual 4: Actual vs. Model-Predicted Trading Volume (ML Evaluation)
- **Visual Type:** Scatter Chart.
- **Data Source:** `tableau_ml_predictions`.
- **X Axis:** `actual_vol_usd` (Logarithmic scale).
- **Y Axis:** `predicted_vol_ols_usd` (Logarithmic scale).
- **Legend:** `asset_type`.
- **Analytics Pane:** Add a Trend line ($y = x$ benchmark).
- **Insight:** OLS log-log model achieves test $R^2 = 0.487$; points above the 45° line indicate assets trading below expectation (Circle USYC), while points below indicate high-turnover trading tokens (Tether, Pepe).

#### Visual 5: Statistical Hypothesis Testing Summary Card
- **Visual Type:** Table or Matrix.
- **Data Source:** `tableau_hypothesis_tests`.
- **Columns:** `test_id`, `name`, `test_statistic`, `p_value`, `effect_size`, `decision`.
- **Conditional Formatting:** Format `decision` background as Light Coral for "Reject H0" and Light Gray for "Fail to Reject H0".

## 4. Tableau Integration & Visual Construction

### Step 4.1: Data Ingestion
1. Open **Tableau Desktop** or **Tableau Public**.
2. In the left navigation, click **To a File → Text file**.
3. Select `tableau_exports/tableau_crypto_daily_panel.csv`.
4. Add New Connection → Text file → Add `tableau_crypto_summary_by_asset.csv`.
5. Join or Relate them on `Name = Name`.

### Step 4.2: Visual Recipes for Tableau

#### Sheet 1: Market Cap Concentration Pareto View (Q1)
1. Drag `Name` to **Columns**.
2. Drag `Market Cap` to **Rows** (Measure: Average).
3. Sort `Name` descending by `Market Cap`.
4. Hold `Ctrl` and drag a second `AVG(Market Cap)` to **Rows** (Dual Axis).
5. On the second pill, right-click → **Quick Table Calculation → Percent of Total**, then right-click again → **Secondary Calculation → Running Total**.
6. Change first mark to **Bar**, second mark to **Line** (Color: Orange).

#### Sheet 2: Weekend vs. Weekday Trading Slump (Q13 / Test 1)
1. Drag `Is Weekend` to **Columns**.
2. Drag `Vol 24h` to **Rows** (Measure: Average or Box Plot).
3. Add a Reference Line showing the overall Mean.
4. Annotate: Weekday Mean = $189.3 bn, Weekend Mean = $120.2 bn (Difference: -$69.1 bn, $p < 0.001$).

#### Sheet 3: Return Normality & Heavy Tail Audit (Q5 / Test 3)
1. Drag `Chg 24h` to **Columns**.
2. Create Bins on `Chg 24h` (Size: 1.0%).
3. Drag `Chg 24h (bin)` to **Columns**, `CNT(Chg 24h)` to **Rows**.
4. Observe sharp peak and extreme tails exceeding $\pm 25\%$ (Excess Kurtosis $\approx 350$).

#### Sheet 4: ML Prediction Residuals (OLS vs. Actual)
1. Use data source `tableau_ml_predictions.csv`.
2. Drag `Actual Vol Usd` to **Columns** (Set axis to Logarithmic).
3. Drag `Predicted Vol Ols Usd` to **Rows** (Set axis to Logarithmic).
4. Drag `Name` to **Detail** and `Asset Type` to **Color**.
5. Add reference line with slope 1 ($Y = X$).

# Cryptocurrency Market Behaviour Analysis

**Course:** 23CSE351 – Foundations of Data Science

A data science case study analysing cryptocurrency market behaviour using Python, statistical hypothesis testing, machine learning, and interactive data exports for Tableau and Power BI.

## Project Overview

This project analyses cryptocurrency market snapshots across **71 assets and 109,130 records**. It includes data preprocessing, exploratory data analysis (EDA), 15 analytical research questions, 7 hypothesis tests, and trading-volume prediction using Ordinary Least Squares (OLS) regression and Random Forest.

The project also provides a Flask REST API and CSV exports for business intelligence dashboards.

### Key Features

- Data cleaning, preprocessing, and data quality checks.
- Exploratory analysis of cryptocurrency prices, returns, volume, and market capitalisation.
- 15 research questions with numerical results and interpretations.
- 7 statistical hypothesis tests.
- OLS regression and Random Forest trading-volume prediction.
- Flask REST API with automated tests.
- CSV exports for Tableau and Power BI.

## Installation and Setup

Run the following commands from the **project root directory**.

### 1. Install dependencies

```bash
python -m pip install -r app/requirements.txt
```

### 2. Run the automated API tests

```bash
python app/backend/test_api.py
```

The current test suite contains 11 tests covering the health check, dataset summary, cryptocurrency listing, historical trends, EDA, research-question endpoints, hypothesis tests, model results, predictions, and CSV exports.

### 3. Start the Flask API

```bash
python app/backend/app.py
```

The API will be available at:

- Base URL: `http://127.0.0.1:5000`
- Health check: `http://127.0.0.1:5000/api/health`

Stop the server with `Ctrl+C`.

## API Reference

### General and dataset endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/health` | Server health and analysis-engine status |
| GET | `/api/dataset-summary` | Dataset summary and data-quality information |
| GET | `/api/cryptocurrencies` | List tracked cryptocurrencies |
| GET | `/api/historical-trends?asset=Bitcoin&limit=200` | Historical data for a selected asset |
| GET | `/api/eda` | Descriptive statistics and correlation information |

The cryptocurrency endpoint supports filtering by asset type, for example `?type=Volatile` or `?type=Stable-value`.

### Research questions and hypothesis tests

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/analysis-questions` | List the 15 research questions |
| GET | `/api/analysis/<question_id>` | Results for an individual research question |
| GET | `/api/hypothesis-tests` | Results for all 7 hypothesis tests |
| GET | `/api/hypothesis-tests/<test_id>` | Details for an individual hypothesis test |

### Machine learning

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/model-results` | Model metrics, coefficients, and evaluation results |
| POST | `/api/predict-volume` | Predict 24-hour trading volume using the available models |

Example prediction request:

```json
{
  "market_cap": 85000000000,
  "chg_24h": 4.5,
  "chg_7d": 12.0,
  "asset_type": "Volatile",
  "is_weekend": false
}
```

Send the request as JSON to `/api/predict-volume`. The response contains the predictions produced by the configured models.

### Tableau and Power BI exports

| Endpoint | Export file |
|---|---|
| `/api/export/daily-panel` | `tableau_crypto_daily_panel.csv` |
| `/api/export/summary-by-asset` | `tableau_crypto_summary_by_asset.csv` |
| `/api/export/hypothesis-tests` | `tableau_hypothesis_tests.csv` |
| `/api/export/ml-predictions` | `tableau_ml_predictions.csv` |

The backend generates these exports during initialization. Start the Flask server before accessing the live HTTP export endpoints.

## Analysis and Methodology

The project includes:

- Data cleaning and coverage analysis.
- Daily-panel construction and asset-level summaries.
- Descriptive statistics, skewness, kurtosis, and correlation analysis.
- Seven statistical hypothesis tests using methods including Welch's t-test, Mann–Whitney U, permutation testing, Levene's test, Shapiro–Wilk, Wilcoxon signed-rank, Kruskal–Wallis, and chi-square testing.
- OLS regression with log-transformed variables and diagnostic analysis.
- Random Forest regression for comparison with OLS.
- Time-based model evaluation and prediction exports.

The exact test, variables, sample size, and interpretation depend on the individual research question.

# Cryptocurrency Market Behaviour Analysis

An end-to-end data science case study exploring cryptocurrency market behaviour through data analysis, statistical techniques, visualizations, and an interactive web application.

🌐 **Live Demo:** [Cryptocurrency Market Behaviour Analysis](https://cryptocurrency-market-behaviour-analysis.onrender.com)

---

## 📌 Project Overview

The cryptocurrency market is known for its volatility, rapid price movements, and differences in trading behaviour across digital assets. This project analyzes historical cryptocurrency market data to explore price trends, market fluctuations, and statistical patterns.

The project combines data preprocessing, exploratory data analysis, statistical analysis, and interactive visualization to make cryptocurrency market behaviour easier to investigate and understand.

## 🎯 Objectives

- Analyze historical cryptocurrency market data.
- Explore price movements, returns, and volatility.
- Compare behavioural patterns across cryptocurrencies.
- Apply statistical methods to investigate market characteristics.
- Present findings through visualizations and an interactive web interface.

## ✨ Key Features

- **Market Overview:** Explore the cryptocurrency dataset and its key characteristics.
- **Dataset Exploration:** Examine historical market records and available variables.
- **Data Science Analysis:** Investigate market behaviour using analytical and statistical techniques.
- **Interactive Web Application:** Access project analysis through a browser-based interface.
- **Tableau Visualization:** Explore the supplementary interactive dashboard.

## 💻 Run Locally

### Prerequisites

- Python 3
- Git

### 1. Clone the repository

```bash
git clone https://github.com/Vaishnavi090807/Cryptocurrency-Market-Behaviour-Analysis.git
```

### 2. Navigate to the application directory

```bash
cd Cryptocurrency-Market-Behaviour-Analysis/app
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Start the application

```bash
python backend/app.py
```

Open the local address displayed in your terminal, typically:

`http://127.0.0.1:5000`
